# palefire

Website built on the [Miniport](https://html5up.net/miniport) template by HTML5 UP.

## Editing

- `index.html` — page content (text, sections, links).
- `assets/css/main.css` — styles (edit directly), or `assets/sass/main.scss` if you compile Sass.
- `assets/js/` — scripts (`main.js` is the template's own logic).
- `images/` — replace `pic00.jpg`–`pic06.jpg` with your own images (keep names or update `index.html`).

Preview locally by opening `index.html` in a browser.
